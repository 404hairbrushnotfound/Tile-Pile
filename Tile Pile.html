What is Tile Pile?

Tile Pile is a sandbox game that I created to play in class while making it appear as though I am actually working. You simply type the name of the "Tile" you want in a given box, and voila, it is there.

How to run game:

The great thing about Tile Pile is that you don't need any fancy software to run it, or even modify it. It works in Microsoft Excel, or in Google Sheets. For Ecxel, simply download the template file, open, and start playing. You can then save the map, and reload the template file to start a new creation.

For Google Sheets, open a new document, then go to File> Open> Upload> Tile Pile [current version].xlts (excel template file). Alternatively, you can also open any maps you have created into Sheets.
