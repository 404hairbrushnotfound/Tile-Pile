Go to the version you want and click the file name. You should see "Raw". Click that to download the game. 
The html doc is supposed to explain how the game works. Essentially, type the name of a "Tile" (Stone, wood, brick, path, water and grass; plus gold, leaves, and log in 1_1) anywhere on the grid. It will appear. Thank you, conditional formatting.
1_1 has a scoring feature. The more things you build, the more coins you earn. Placing gold costs money, though.
There's also a multiplayer feature. Make the excel file a shared doc and place a bunch of gold on your friend's side of the map.
Conditional formatting can be a bit buggy at times. Enjoy!
